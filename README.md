# Emoji Finder

Адаптивная верстка экрана [Emoji Finder из Figma](https://www.figma.com/design/HCciSRJI0qWzJwNoK6mb4b/%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D1%8B-React?node-id=9249-18) на React, TypeScript и Vite. Для расположения элементов используются CSS Flexbox и Grid. Поиск фильтрует карточки по названию и ключевым словам.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run lint
npm run build
```

Шрифт Inter подключен через CSS `@import`.
